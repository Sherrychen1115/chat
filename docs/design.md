# 畫面設計結果

這份文件整理 `/design` 做出來的畫面設計,給做前端(`/frontend-design`)時使用。畫面的行為規則以 `docs/architecture.md` 第 7 節為準,這份文件只記錄「長什麼樣子」。

- **設計稿連結**:https://claude.ai/artifact/1PCT6DU2Vw9YC2gs5P1GtA(私人連結,只有建立者能開,要給別人看需從頁面的 Share 選單分享)
- **風格**:手機優先、淺色、青綠色主色。這是我(Claude)在你沒指定風格時預設的,不是你選的,想換可以隨時改。
- **性質**:靜態設計稿,按鈕不會動。範例訊息和代號(小明、小美、阿星、大雄、靜香、阿花)都是假內容。

## 2. 設計變數

### 顏色

| 用途 | 色碼 |
|---|---|
| 頁面背景 | `#F3F5F7` |
| 卡片、頂部列、輸入區背景 | `#FFFFFF` |
| 分隔線、別人訊息的邊框 | `#DDE3E8` |
| 輸入框邊框(一般) | `#8A97A4` |
| 停用元件的邊框 | `#C5CED6` |
| 停用輸入框的背景 | `#E9EDF1` |
| 主文字 | `#16202A` |
| 次要文字(時間、系統提示、說明) | `#566370` |
| 主色(按鈕、自己的訊息、焦點框) | `#0F766E`,上面的文字是白色 |
| 主色淺底(自己在名單上那一列、展開中的人數鈕) | `#E3F2F0` |
| 在線小圓點 | `#1A7F4B` |
| 錯誤、離開按鈕 | `#B42318` |
| 提醒橫條(連線中、代號被拿走) | 底 `#FFF4D6`,字 `#7A4B00` |
| 載入骨架 | `#E4E9ED`、`#DDE3E8` |

文字和底色的對比有注意到至少 4.5:1,實作時請不要換成更淡的灰。

### 字型

- `Noto Sans TC`(Google Fonts,字重 400、500、700),後備 `system-ui`、`PingFang TC`。
- 大小:頁面大標 28px;頂部名稱 17px;訊息內容 15px;代號與時間、系統提示、說明文字 12 到 14px。
- **輸入框字體必須 16px 以上**,否則 iPhone 輸入時會自動放大畫面。

### 形狀與尺寸

- 所有可點的東西高度至少 **44px**(按鈕、輸入框、名單項目)。
- 訊息泡泡:圓角 16px,靠近發話者那一角縮成 4px(別人的左上角、自己的右上角)。
- 輸入框和人數鈕是膠囊形(圓角 22px);輸入代號的框和按鈕圓角 12px。
- 手機頂部列高 56px;電腦版線上名單寬 280px;電腦版訊息欄最寬 760px,置中。
- 焦點框:2px 主色,外移 2px。

## 3. 畫面結構

### 輸入代號(手機,單欄置中)

由上到下:標誌、標題「匿名聊天室」、一句說明、「你的代號」標籤、輸入框、說明列(左:「1 到 12 個字,中英文數字都可以」,右:字數 `0/12`)、進入按鈕。錯誤訊息取代說明列左側的文字。「重連後代號被拿走」的黃色提示放在標題區和表單之間。

### 聊天室(手機)

由上到下:頂部列、(連線中斷時)黃色橫條、訊息列表、輸入區。
- **頂部列**:左邊「匿名聊天室」,右邊「N 人在線」膠囊鈕(綠點、人數、向下箭頭)和紅色「離開」。
- **訊息列表**:可捲動,左右各留 16px;「有新訊息」按鈕浮在列表底部中央,蓋在訊息上。
- **輸入區**:白底,上方細線;輸入框加圓形送出鈕。
- **展開線上名單**:在訊息列表上方蓋一層半透明深色,名單卡片靠頂部浮出,左右各離邊緣 12px。人數鈕變成主色框、淺底、箭頭向上。

### 聊天室(電腦)

頂部列只有名稱和「離開」(沒有人數鈕)。下方左右分欄:左邊是訊息列表加輸入區,右邊是 280px 的線上名單,標題「在線 N 人」。

## 4. 元件規格

### 4.1 訊息

| 種類 | 對齊 | 內容 |
|---|---|---|
| 別人的訊息 | 靠左,最寬 80%(電腦版 70%) | 上方一行小字「代號 · 時間」(代號較深、較粗),下方白底有邊框的泡泡 |
| 自己的訊息 | 靠右,同樣最寬 | 上方也顯示自己的代號和時間,下方主色底、白字的泡泡 |
| 系統提示 | 置中 | 12px 次要文字,例如「小明 進來了」「阿花 離開了」,沒有泡泡 |

- 換行要保留(`white-space: pre-line`)。
- 一長串沒有空白的字要能換行(`overflow-wrap: anywhere`)。
- 網址只顯示成純文字,不做成連結。
- 訊息一律當純文字顯示,不可以把內容當成網頁解讀。

### 4.2 線上名單

- 每一列:綠點、代號;自己那一列有淺底和一個「你」的小標籤。
- 手機版名單頂部有一行「目前在線 N 人」;電腦版標題「在線 N 人」,前面有人群圖示。
- 列高:手機 44px,電腦 40px。

### 4.3 「有新訊息」按鈕

主色膠囊,高 44px,向下箭頭加「有新訊息」,有陰影。只在往上捲動又有新訊息時出現;點了跳到最底並消失。

### 4.4 輸入區的 6 種狀態

| 狀態 | 畫面 |
|---|---|
| 空白 | 提示文字「輸入訊息…」;送出鈕停用(半透明) |
| 輸入中 | 輸入框變主色框,可多行;送出鈕可按 |
| 接近 500 字 | 輸入框上方靠右顯示「還可輸入 N 字」(次要文字色) |
| 超過 500 字 | 輸入框變紅色粗框;上方靠右紅字「超過 N 字,無法送出」;送出鈕停用 |
| 送太快 | 上方紅字「送太快了,請稍等」;輸入框和送出鈕都停用,提示文字「請稍等一下再送出」 |
| 送出失敗 | 上方紅字,說明原因,例如「送出失敗,網路不穩,請再試一次」;輸入框紅框,**原本打的文字保留**;送出鈕可按 |

連線中斷時輸入框停用,提示文字「連線恢復後才能送出」。

### 4.5 其他狀態

- **載入中**:幾個灰色的泡泡骨架,中央「載入訊息中…」加轉圈圖示。
- **空狀態**:淺色圓形圖示、「還沒有人說話」、「送出第一則訊息,開啟這個聊天室。」
- **連線中斷**:頂部列下方黃色橫條,轉圈圖示加「連線中…」。
- **分頁標題**:背景有未讀時 `(3) 匿名聊天室`;回到分頁後 `匿名聊天室`。

## 5. 圖示

用內嵌的線條 SVG(2px 線寬、圓角端點),不用表情符號。用到的圖示:對話框(標誌、空狀態)、人群(電腦版名單標題)、向下和向上箭頭、登出(離開)、送出(紙飛機)、轉圈、警示圈(代號被拿走提示)。純裝飾的圖示要加 `aria-hidden`,只有圖示沒有文字的按鈕要有 `aria-label`(例如送出、展開線上名單)。

## 6. 無障礙與手機的注意事項

- 用真正的 `<button>`、`<label>` 加 `<input>`、`<textarea>`,不要用 `div` 假裝按鈕。
- 錯誤提示和連線狀態要能被螢幕閱讀器念出(`role="alert"`、`role="status"`)。
- 手機鍵盤彈出時,輸入框和最新訊息要保持看得到。
- 手機版的頂部列要能放得下:名稱、人數鈕、離開鈕,在 390px 寬時不換行。

## 7. 設計稿和實際要求的差異,做前端時要注意

- 設計稿是靜態的,沒有畫出:捲動行為、鍵盤快捷鍵(電腦 Enter 送出、Shift+Enter 換行,手機 Enter 換行)、字數即時計算、「送太快」幾秒後自動恢復、分頁標題真的改變。這些要照 `docs/architecture.md` 第 6、7 節實作。
- 設計稿的「超過上限」範例用的是假文字,實際的字數上限是 500。
- 電腦版名單放在右側是我決定的,你沒指定,想放左側可以改。
- 「連線中」橫條和黃色提示用同一組黃色;如果之後想區分嚴重程度,再調整。
